Configuración inicial

Para usar la app, conecta tu backend de Google Apps Script. La URL y el token se guardan solo en este dispositivo (localStorage); nunca se envían a ningún otro lugar.

El token lo genera la función setupLibro() del backend y queda en Script Properties. Si cambias de dispositivo, vuelve a capturarlo aquí.
